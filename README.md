# الخرائط التعليمية الذكية

منصة عربية RTL مبنية على مشروع `ehabgis/lamies` الأصلي. React 18 + Vite 7 + React Router 7 + Zustand، وخادم Node.js 24 مع SQLite المدمجة. لم يُستبدل إطار React، ولم تكن توجد قاعدة بيانات سابقة. بقيت الصفحات القديمة مستقلة، وأضيفت المنصة المتصلة بالخادم تحت `src/platform` و`server`.

## التشغيل محليًا

ثبّت **Node.js 24 LTS**. من مجلد `package.json`:

```sh
npm ci
npm run dev
```

يشغّل الأمر الخادم 3100 وVite على 3000 معًا. افتح العنوان الذي يعرضه Vite. إن كان 3000 مشغولًا يختار Vite منفذًا تاليًا؛ لا تضف نجومًا أو `/map**` للعنوان. `npm run dev -- --port 3010 --strictPort` يحدد منفذ الواجهة. إذا كان 3100 مشغولًا أوقف نسختك السابقة أولًا؛ لا تشغّل خادمين على قاعدة واحدة. `START_WINDOWS.cmd` يشغّل التثبيت عند أول تشغيل ثم الخدمتين. اختُبرت الأوامر على Linux؛ لم يُختبر ملف Windows على Windows فعلي.

`npm run dev:client` يشغّل الواجهة فقط، و`npm run server` الخادم فقط. Vite يمرر `/api` إلى 3100. عند تغيير منفذ الخادم حدّث هدف proxy في `vite.config.js` أيضًا.

## تجربة الدرس دون حساب

اضغط **«ابدأ المغامرة»** في صفحة البداية لفتح `/explore`. اختر العام والمرحلة والصف، ثم الفصل الدراسي (المادة ثابتة: الدراسات الاجتماعية)، ثم الوحدة واضغط «ابدأ الدرس» لفتح `/demo/lesson-1`. بعد تسجيل الدخول، تعرض `/journey` الدروس المنشورة، وتحفظ اختيارات التسجيل عند بدء الدرس. هذه نسخة ثابتة من المحتوى التجريبي المرفق، تحمل تنبيه عدم الاعتماد في أعلى الصفحة. تعمل الخريطة ووضعي الاستكشاف والمحافظات والأهداف والمفاهيم والأسئلة والأنشطة؛ يصحّح الخادم إجابات التجربة ويعرض التلميحات المكتوبة. لا يحتاج الزائر إنشاء حساب أو مشرف.

لا تُنشر مسودة CMS تلقائيًا، ولا تُحفظ محاولات أو درجات أو نقاط في قاعدة البيانات، وتُمسح إجابات هذه التجربة عند التحديث. التجربة لا تكشف إجابات الأسئلة قبل المحاولة الصحيحة. OpenAI غير مفعّل داخلها ولا يُعرض النص الثابت بوصفه ردًا مولدًا. الدروس الرسمية والحسابات والإدارة تبقى منفصلة. تستعمل التجربة صور Esri الفعلية مع بديل محلي واضح عند الانقطاع؛ الوسائط غير المرفقة تظهر حالتها بوضوح.

## أول حساب إدارة

لا توجد كلمة مرور افتراضية أو مشرف مسجل داخل الأرشيف. في PowerShell من مجلد المشروع:

```powershell
powershell -NoProfile -File .\SETUP_ADMIN.ps1
```

الأمر يسأل عن بريد المشرف واسمه وكلمة مروره دون إظهارها. إذا منعت سياسة جهازك تشغيل السكربت استخدم أوامر PowerShell المفصلة في [دليل الخادم](server/README.md) بدل تغيير سياسة الجهاز. في Bash اتبع القسم نفسه أو مرر ADMIN_EMAIL وADMIN_PASSWORD مؤقتًا إلى `npm run bootstrap`. لا يغيّر bootstrap حسابًا موجودًا. يستطيع الطلاب إنشاء حساب باسم مستخدم مستعار دون بريد.

بعد الدخول بالإدارة افتح `/admin`. راجع درس `lesson-1` ووحدته، وأضف مصادر صحيحة، وفعّل اعتماد المصدر بعد مراجعة بشرية، وألغِ `reviewRequired`، ثم انشر الوحدة والدرس. يجب نشر جميع الأسلاف أيضًا. **لا تنشر المحتوى تلقائيًا لتجربة الواجهة**؛ زر معاينة المسودة يعمل لحساب الإدارة قبل النشر.

## ما يعمل

- حسابات خاصة وجلسات HttpOnly، وأدوار Super Admin / Content Admin / Teacher / Student. دور Parent محجوز ولا يعرض بيانات أطفال دون ربط وصي لاحق.
- تسلسل ديناميكي مرحلة ← صف ← فصل ← عام ← مادة ← وحدة ← درس، مع ترتيب وتعطيل ونشر وإصدارات واستيراد/تصدير. العام هنا عقدة داخل الفصل لتحديد النسخة؛ يمكن تكراره لكل مسار دون تثبيت الصفوف داخل الواجهة.
- نماذج مرئية للمحتوى والمصادر والمفاهيم والموارد والمواقع والأسئلة، ورفع وسائط حقيقي. JSON متقدم اختياري.
- تسجيل الطالب حسب المرحلة والصف والفصل والعام، ودروس منشورة حسب تسجيله.
- وضع اكتشاف يبدأ بلا رموز موارد، ووضع استكشاف يعرض الجميع، وبطاقات عند اختيار الموقع؛ أهداف ومفاهيم في لوحة فوق الخريطة.
- طبقة المحافظات الـ27 من Natural Earth، أسماء عربية واختيار بالنقر أو القائمة، وتكبير وتصغير. حدود معمّمة تعليمية وليست مرجعًا رسميًا؛ [الترخيص](public/geodata/LICENSE.txt).
- اختيار، صح/خطأ، ترتيب، مطابقة، سحب وتصنيف مع بديل لوحة مفاتيح، تحديد موقع، إكمال فراغ، ومطابقة رموز/صور. المعاينة لا تحفظ درجات؛ الطالب يُصحّح على الخادم فقط.
- نتائج ومحاولات ونجوم ونقاط وإكمال محفوظة في SQLite، ومكافأة الإكمال مرة واحدة. يستعيد الدرس المورد والموقع ووضع الخريطة، ولوحة الطالب تعرض آخر درس.
- تقارير وصلاحيات على الخادم؛ المعلم يرى الطلاب المسندين له فقط.
- ربط OpenAI من الخادم مع استرجاع لفظي من مصادر مراجعة، وموافقة إرسال واضحة، والتحقق من معرفات الاستشهادات. «سؤال إضافي» يختار من بنك أسئلة مُراجع، ولا يعتمد إجابة مولّدة غير متحققة.

## ما يحتاج مدخلات قبل إطلاق تعليمي حقيقي

المحتوى المرفق وصف تجربة وصور مرجعية، وليس كتاب المنهج الرسمي. البذرة مسودة لا تُعرض للطلاب قبل المراجعة. الصفان الرابع والسادس والفصل الثاني قابلون للإدارة لكن ليس لهم دروس معتمدة مرفقة. الإحداثيات السابقة تقريبية، وتنقص نقاط الكريمات وجبل الزيت والفحم. لا توجد فيديوهات مرخصة أو صور خامات معتمدة ضمن البذرة. لا تُستبدل بصورة تخمينية ولا يُدّعى تشغيل فيديو غير موجود. خريطة الدرس الأساسية صور Esri World Imagery الفعلية عبر الإنترنت، مع معرض للشوارع والتضاريس وخريطة محلية عند الانقطاع. هذه ليست صورًا لحظية؛ النسب والمصدر ظاهران داخل الخريطة.

نشاط «اصنع خريطتك» يقبل إسقاط رمز واحد قرب إحدى نقاط السؤال ضمن مسافة عرض نسبية 7% ثم يرسل معرف الموقع للخادم؛ هذا تسامح لمس تعليمي وليس معيار مسافة جغرافية. تتوفر أزرار وأسماء كبديل للسحب. بيانات المناطق المقبولة وأحجامها تحتاج مراجعة تربوية قبل أن يصبح النشاط اختبارًا جغرافيًا دقيقًا. الخرائط العالمية وإدارة الطبقات الجغرافية الجديدة من CMS لم تُنفذ؛ طبقة المحافظات متاحة محليًا، وموارد الدرس قابلة للإدارة.

راجع [مراجعة المحتوى](docs/CONTENT_REVIEW.md) قبل النشر. شاشة المحادثة لا تجعل النص الثابت ذكاءً اصطناعيًا، والاختبارات التقنية لا تثبت الاعتماد الرسمي أو صحة كل معلومة.

## OpenAI

انسخ `.env.example` إلى `.env` وأضف `OPENAI_API_KEY` في بيئة الخادم فقط. يمكن أيضًا إدخاله بأمان من إعدادات بيئة Codex؛ **لا ترسله في الشات ولا تضعه في VITE_ أو public**. `OPENAI_MODEL` اختياري. نحتاج مصادر `approved:true` بعد مراجعة بشرية قبل أي استرجاع. لا تُرسل أسماء الطلاب أو نتائجهم؛ يُرسل السؤال وسياق الدرس الموافق عليه. دون مفتاح تظهر حالة غير مهيأة، ولا تُختلق إجابة. اختُبر المسار بمزود اختباري؛ لم يُختبر اتصال OpenAI حي لغياب المفتاح. الاسترجاع لفظي أعلى 3 فقرات، لا بحث دلالي، وقد يرفض سؤالًا يحتاج إعادة صياغة.

## خريطة في شاشة واحدة

معرض خرائط الأساس بجوار زر المحافظات داخل الخريطة. يعمل دون إضافة مفتاح Esri في هذا الإعداد، مع إبقاء نسبة المصدر. على الهاتف افتح «مفتاح الخريطة» أو «المعلم والمعلومات» بدل التمرير بين أعمدة طويلة. تبقى الأسئلة والأنشطة فوق نفس الخريطة. تفاصيل الخدمات والإحداثيات والبديل المحلي في [دليل الخرائط](docs/MAP_SOURCES.md).

## الاختبارات

```sh
npm run check
npm test
npm run build
```

`npm test` يفتح خادم HTTP وقواعد مؤقتة: المصادقة، CSRF، الأدوار، المسودات، التسجيل، جميع أنواع الإجابات، منع تكرار المكافأة، إصدارات واستيراد ذري، وسائط، التقارير، استعادة الحالة بعد إعادة تشغيل الخادم، ومخرجات AI غير موثوقة. الأدوات لا تختبر اتصالًا حيًا بلا مفتاح.

## المسارات والحفاظ على الأصل

المنصة: `/`، `/journey`، `/classroom/:id`، `/my-progress`، `/admin`.

النسخة السابقة: `/legacy`، `/home`، `/lessons`، `/map`، `/lesson/:lessonId`، `/awards`، `/quiz/:locationId`. مكافآت النسخة السابقة محلية مستقلة، وليست النتائج الموثقة بالحساب. لا تستخدمها لتقارير المنصة. الصوت أصبح اختيارًا افتراضيًا ولا يعمل تلقائيًا للزائر الجديد.

## النشر والنسخ الاحتياطي

`npm run build` ينتج `dist`. الخادم API فقط؛ في الإنتاج استخدم خادم HTTPS يقدم dist مع SPA fallback ويمرر `/api` إلى Node. اضبط `APP_ORIGIN` إلى أصل الواجهة الكامل و`COOKIE_SECURE=true`، وشغّل Node على loopback أو شبكة خاصة. لا تستخدم Vite dev للنشر. دليل المتغيرات وAPI والمخاطر التشغيلية في [server/README.md](server/README.md).

قاعدة البيانات وملفات الرفع في `server/data`، مستثناة من Git والأرشيف. احتفظ بنسخة منها معًا بعد إيقاف الخادم، ولا تعِد تهيئة قاعدة مستخدمة لإضافة بذرة جديدة. تغييرات المخطط عبر migrations المرقمة. رُفع فرع feature/lamis-platform إلى GitHub بإذن المستخدم؛ لم يُنشر موقع إنتاج.


تحديث شاشة الاختيار: تضم التجربة الصفوف الرابع والخامس والسادس والفصلين وثلاث وحدات لكل مسار. الوحدة الثالثة تعرض الثروة المعدنية ومصادر الطاقة، وموارد المياه، والمشروعات القومية. أصبحت دروس الثروة المعدنية والمياه والمشروعات متاحة للصف الخامس كتجارب مسترجعة من بيانات المشروع القديم، وتُتاح للفصلين كعينة دون اعتماد توزيع المنهج. بقية الوحدات والصفوف قيد التجهيز. في الحسابات التي لا تحتوي دروسًا منشورة، يظهر هذا الهيكل التجريبي بوضوح ولا يحفظ نتائج رسمية. بطاقة المورد تظهر جانبًا، والفيديو في نافذة فوق الخريطة. يمكن طي مفتاح الخريطة وبطاقة المعلومات وإعادة فتحهما، والتنقل بين الدروس من القائمة العلوية. «عرض الجميع» يعيد كل الرموز ويسترجع عرض مصر بعد التكبير. إرفاق الصورة من البطاقة معاينة محلية؛ الحفظ المشترك من محرر المورد بالإدارة.

صفحة الخريطة الحالية تملأ الشاشة أسفل أزرار الدروس الثلاثة وأزرار الأهداف والمفاهيم والمعلومات، مع اسم الوحدة والطالب. توجد بقية أدوات الدرس والأسئلة والأنشطة وروابط الحساب داخل قائمة المفتاح والأدوات؛ بطاقة المورد في قائمة منفصلة. تفتح قائمة واحدة في كل مرة، ويمكن طيها لعرض الخريطة كاملة دون فقد الاختيار. انظر [توثيق الخريطة بطول الشاشة](docs/FULL_HEIGHT_MAP.md).


استرجاع الدروس القديمة وأزرار التنقل الملونة ولوحات تفاصيل الدرس موثقة في [دليل تحديث الدروس](docs/LESSON_BUTTONS_AND_LEGACY.md). الوسائط المشار إليها في بيانات الدروس القديمة غير مرفقة حاليًا؛ يظهر ذلك صراحةً داخل المعلومات.
