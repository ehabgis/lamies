# صفحة البداية

الاسم الظاهر: «الخرائط التعليمية الزكية» كما طلب المستخدم. حافظ التصميم على المستكشف والكرة الأرضية والخط العربي المحلي، وأضاف خطوات الرحلة ودخولًا مباشرًا للدرس التجريبي.

الحركة افتتاحية محدودة، مع زر إيقاف، وتعطيل تلقائي عند prefers-reduced-motion. لا يوجد صوت تلقائي. بقي تسجيل الدخول وإنشاء الحساب ومسارات النسخة السابقة متاحة.

التحقق: npm run check، npm test (5/5)، npm run build. متصفح Chromium: فتح التجربة، خطأ بيانات الدخول وزر المحاولة مجددًا، تبديل التسجيل ومسح الخطأ، إيقاف الحركة وتقليلها. لا إنشاء لحسابات اختبار دائمة.

فحص العرض: 1440×900، 1366×768، 390×844، 360×740، 844×390. الصفحة ضمن ارتفاع الشاشة في الحالات العادية؛ النموذج يتمرر داخليًا على الشاشات الأفقية القصيرة وعند الحاجة بدل قص الأزرار. لا تمرير أفقي. لقطتا ENTRY_DESKTOP.png وENTRY_MOBILE.png في screens تعرضان حالة الدخول الافتراضية.

لم يُختبر فتح لوحة مفاتيح هاتف فعلي أو تشغيل Windows في هذه الجولة؛ الإتاحة تبقى قابلة للتمرير عند ضيق الارتفاع أو تكبير النص.
