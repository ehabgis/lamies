# خريطة بطول الشاشة

أعلى صفحة الدرس شريط واحد لاختيار الدرس واسم الوحدة الفعلي من الكتالوج واسم الطالب من الجلسة. للزائر «مستكشف زائر». أزيل رأس العلامة الكبير من صفحات الخريطة فقط؛ بقية الصفحات تحتفظ به. نقلت روابط البداية والرحلة والإنجازات والإدارة والخروج إلى قائمة الأدوات عبر PlatformNavigation مشتركة، دون تغيير صلاحياتها.

الخريطة تمتد إلى أسفل الشاشة دون شريط أنشطة سفلي أو شريط إعدادات فوقها. تضم قائمة المفتاح: وضع العرض ودليل الأهداف والمفاهيم والمعلومات، الموارد، إعادة عرض الجميع، الأسئلة والأنشطة والمساعد والإكمال، وروابط التنقل. تبقى قائمة المعلم والمورد للشرح والبطاقة والصورة والفيديو. أزرار فتح القائمتين على حافتي الخريطة، وتفتح قائمة واحدة في كل مرة للحفاظ على المساحة؛ تتذكر البطاقة المورد عند الطي. اختيار موقع يقربه ويفتح بطاقته ويطوي المفتاح. التمرير داخل القوائم فقط. أدوات Esri الأصلية والتكبير والإسناد تبقى فوق الخريطة.

قياسات Chromium: مساحة سطح الخريطة نحو 89.1% عند 1440×900، و87.4% عند 1366×768، و82.2% عند 390×844، و80.0% عند 360×740، و68.6% في الوضع الأفقي 844×390. مع قائمة المفتاح المفتوحة بقيت المساحة الظاهرة نحو74.2% و72.3% على الكمبيوتر، ومع بطاقة مورد عند1440×900 نحو72.8%، أي أكثر من الثلثين. هذه قياسات على المقاسات المذكورة لا ضمان لكل تكبير نص أو جهاز.

تحقق المتصفح: تحميل Esri الفعلي قبل التقاط FULL_MAP_1440.png وFULL_MAP_390.png، عرض اسم الوحدة، اسم الزائر، واسم طالب باستجابة جلسة اختبارية. اختبرت إعدادات وأهداف الدرس داخل القائمة، فتح الأسئلة وإغلاقها، اختيار الموقع وبطاقته والفيديو، طي القائمتين وإعادة فتحهما، وإعادة جميع الرموز وإزالة التحديد بعد الزوم. لا تمرير خارجي أو أخطاء JavaScript في المقاسات الخمسة. لم يُنشأ حساب دائم ولم تتغير المكافآت أو صلاحيات الصور.

npm run check، npm test (5/5)، npm run build. هذا التصميم يستبدل الشريطين العلوي والسفلي المذكورين في توثيق مساحة الخريطة السابقة.
