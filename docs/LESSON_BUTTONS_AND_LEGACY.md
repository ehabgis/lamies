# أزرار الدروس وبيانات النسخة السابقة

أزيلت قائمة اختيار الدرس واستبدلت بثلاثة أزرار: الأول بالأزرق والثاني بالأخضر والثالث بالبنفسجي. يبرز الدرس الحالي، ويظهر الاسم الكامل عند hover أو التركيز بلوحة المفاتيح؛ تربطه aria-describedby بالزر. يبقى غير المتاح قابلًا للتركيز لشرح حالته دون التنقل إلى مسار مكسور.

في نفس الشريط أهداف الدرس ومفاهيمه ومعلوماته. كل زر يفتح لوحة غير حاجزة أعلى يمين الخريطة، بعرض حتى420px وارتفاع محدود مع تمرير داخلي. الإغلاق أو Escape يعيدان التركيز إلى الزر. تبديل الدرس يمسح اللوحة وحالة السؤال والموقع، مع تجاهل استجابة درس قديم إن سبقها طلب أحدث. بقيت الوحدة واسم الطالب والقوائم القابلة للطي والخريطة الكبيرة.

المصدر القديم src/data/curriculumData.js يتضمن ثلاثة دروس و21 موقعًا. server/legacy-content.mjs يحول الأهداف والمفردات والملخص والشرح والنقاط والأمثلة وتطبيقات الحياة والمعلومات الإضافية والأسرار والمواقع وحواراتها وأسئلة التدريب والمواقع إلى عقد المنصة. بقيت الإحداثيات كما وردت، وأضيف رمزان واضحان للمياه والمشروعات. درس1 يحافظ على محتوى seed-content.json الحالي ويضيف المحتوى القديم؛ المياه والمشروعات أصبحا تجربتين مستقلتين. لا إعادة تهيئة لقاعدة مستخدمة أو استبدال تحرير الإدارة، ولا نشر أو اعتماد تلقائي. بيانات المستويات والمكافآت والإعدادات الأصلية محفوظة في المصدر وlegacyArchive، ولا تُخلط بنقاط الخادم.

حصيلة العرض الحالي: الأول7 أهداف و8 مفاهيم و43 سؤالًا و9 مواقع؛ الثاني3 أهداف و3 مفاهيم و12 سؤالًا و6 مواقع؛ الثالث3 أهداف و3 مفاهيم و9 أسئلة و6 مواقع. إجمالي64 سؤالًا، منها24 سؤال البذرة السابقة و40 من بيانات النسخة القديمة. التصحيح والإجابات في الخادم فقط، ولا يعيد API الإجابات أو تفسيراتها قبل الإجابة الصحيحة. كل المصادر غير معتمدة وreviewRequired=true. تحديث كتالوج التجربة يتيح الثلاثة للصف الخامس في الفصلين كعينة لا توزيع منهجي مثبت، ويُبقي بقية الصفوف والوحدات بحالتها.

هناك22 مرجعًا لوسائط داخل البيانات القديمة، تتكرر بعض مساراتها، ولا يوجد ملف مشار إليه حاليًا في public. تحفظ العناوين والمسارات وتظهر «الملف غير موجود حاليًا» دون رابط تشغيل زائف. docs/LEGACY_MIGRATION.json يسجل التفاصيل والمسارات المميزة. لم تُخترع روابط بديلة، ولم تُنقل أرقام أو ادعاءات قديمة بوصفها مصادر معتمدة. تعرض الواجهة تنبيه المراجعة للمحتوى المنقول، بما فيه تفاصيل المواقع القديمة.

API: /api/demo/lessons/lesson-1 وlesson-2 وlesson-3، وanswers لكل منها. استثناء CSRF يقتصر على مسارات إجابات هذه العينات الثلاث بالاسم؛ حماية Origin وحد المعدل مستمران. تُرفض إجابة سؤال من درس مختلف. لا كتابة لنتائج زائر أو منح XP. لا تُعرض مسودات CMS الأخرى.

التحقق: npm run check، npm test (5/5 يتضمن فحص العينات الجديدة وعزل الأسئلة وحجب الإجابات ومنع Origin أجنبي)، npm run build. Chromium على1440×900 و1366×768 و390×844 و360×740 و844×390: ألوان/عناوين الأزرار، التنقل بين الثلاثة، تطابق عدد المواقع، الألواح الثلاثة وحدودها وإغلاقها وعودة التركيز، وتصحيح سؤال حقيقي من درسي المياه والمشروعات. لا تمرير للمستند أو أخطاءJS. مساحة سطح الخريطة نحو76–89% من الشاشة في المقاسات المختبرة. ليست هذه مراجعة علمية للمحتوى ولا اختبار تشغيل الوسائط المفقودة.

نقطة مراجعة تعليمية محددة: أهداف المشروعات القديمة تتضمن ذكر «براكة» ضمن مشروعات الطاقة؛ لم يُحذف النص أثناء الاسترجاع ولم يُعتمد بوصفه مشروعًا مصريًا. يلزم مراجعة ملاءمته لدرس مصر، مع مراجعة الأرقام والمقارنات الواردة في الحوارات والحقائق القديمة قبل النشر.
