# استكشاف موقع وتبويبات المعلومات

الضغط على رمز الموقع بالفأرة أو Enter/Space يحدد المورد والموقع ويقرب الخريطة إلى مستوى 8 على الأقل، مع الاحتفاظ بتكبير أعلى اختاره المستخدم. دائرة برتقالية واسم ثابت يبرزان الموقع. حركة التقريب تحترم تقليل الحركة. على الهاتف يتغير مركز العرض قليلًا لتبقى العلامة فوق لوحة المعلومات، التي تشغل 62% على الأكثر من مساحة الخريطة.

لوحة المعلومات تعرض تبويبين: الفيديو، والملخص والخصائص (الافتراضي). يمكن تبديلهما بالأسهم وHome/End. الملخص يعرض المعلومات القائمة ونوع المورد والإحداثيات التعليمية التقريبية، مع ملخص الدرس القابل للتوسيع وأدوات الأسئلة والمساعدة السابقة. لا حقائق أو إحداثيات جديدة.

الفيديو يستخدم media.video الموجود للمورد، دون تشغيل تلقائي. تبديل التبويب يزيل المشغل. العرض الأكبر يوقف المشغل الصغير أولًا؛ إغلاقه يعيد نفس الموقع والتبويب دون تشغيل تلقائي. عدم توفر الفيديو وفشل تحميله حالتان واضحتان. الكاميرا على الخريطة تفتح تبويب الفيديو وتقرّب موقعه. العينة المرفقة لا تحتوي فيديو فعليًا؛ لم يضف رابط بديل مزعوم.

تحقق Chromium: بيانات Esri الحقيقية عند مستوى 8، حلقة التحديد، Enter لاختيار الموقع، تبويبات لوحة المفاتيح، التحديد المتكرر بعد إعادة عرض مصر، مقاس 1440×900 و390×844 دون تمرير خارجي، وموقع علامة الهاتف أعلى اللوحة. استجابات API اختبارية لوجود فيديو غير صالح تحققت من عدم التشغيل التلقائي والخطأ وإعادة المحاولة وإزالة المشغل عند تبديل التبويب. لم يختبر تشغيل ملف فيديو كامل أو ملء الشاشة الفعلي في هذه الجولة.

npm run check وnpm test (5/5) وnpm run build ناجحة. لقطات screens/LOCATION_DESKTOP.png وLOCATION_MOBILE.png توثق التجربة.
