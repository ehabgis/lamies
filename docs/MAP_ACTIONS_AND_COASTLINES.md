# أدوات الخريطة وحدود المياه

- «عرض الجميع» زر دائم خارج مفتاح الخريطة: يعيد عرض جميع الموارد وحدود مصر بعد اختيار مورد أو التقريب.
- زر «الأسماء» بجوار «المعلم والمورد» يتحكم في أسماء المواقع مستقلًا عن وضع الاستكشاف. تبقى تسمية الموقع المحدد ظاهرة. للأسماء خلفية كحلية ونص أبيض وحد واضح.
- أزيل رابطا اختيار الدروس وصفحة البداية من المفتاح؛ تبقى أزرار الدروس الثلاثة أعلى الصفحة. لم تتغير روابط الحساب والإدارة والخروج للمستخدم المسجل.
- كُبّرت أزرار الدروس وتفاصيلها ووُسّطت كمجموعة، مع ترتيب متجاوب على الهاتف.
- لوحة أسئلة الدرس والأنشطة والمعلم بعرض يصل إلى560بكسل، وتمتد من أعلى الخريطة إلى شريط التعلم السفلي. المحتوى الطويل يمرر داخل اللوحة؛ لا يحتاج المستند إلى تمرير.

تتبع مناطق البحار الآن تقاطع مناطق Natural Earth البحرية مع طبقة المحيط ذات مقياس1:10m، مع تضمين خليجي السويس والعقبة والحفاظ على فتحات اليابسة والجزر. نفس عائلة بيانات حدود المحافظات، لكنها هندسة تعليمية معمّمة وليست حدودًا مساحية أو بيانات ملاحة. لا تمثل علامة البحر مأخذ مياه عذبة. مصدر الطبقة وبصمتها موثقان في WATER_SOURCE_LEDGER.json.

التحقق: npm run check وnpm test (6 اختبارات ناجحة) وnpm run build. اختبارات المتصفح على1440×900 و1366×768 و390×844 و360×740 و844×390 تحققت من بقاء زر الإعادة خارج القائمة، تبديل8تسميات وخلفياتها، إعادة الموارد بعد التقريب، اتساع لوحة الأسئلة، عدم قص أزرار الأدوات أو تمرير المستند، والإجابة والتصحيح والمطابقة دون أخطاء JavaScript. اختبارات هندسة المياه تتحقق أيضًا من احتواء الخليجين واستبعاد سيناء والدلتا واليابسة قرب الغردقة. لقطات MAP_ACTIONS وEXPANDED_QUESTIONS توثق العرض الحالي.
