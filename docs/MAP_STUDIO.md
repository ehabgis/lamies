# مساحة الخريطة

التحديث يعيد بطاقة المورد إلى الجانب ويخصص العرض فوق الخريطة للفيديو فقط. شريط علوي مضغوط: اختيار الدرس، طي المفتاح والمعلومات، عرض الجميع، وضع الخريطة ودليل الدرس. شريط الأسئلة والأنشطة والمساعدة والإكمال أسفل الخريطة في صف واحد. لا تغيير في Esri أو المواقع أو المحتوى العلمي.

طي القائمتين يوسّع الخريطة، ويمكن فتحهما من نفس الأزرار. على الهاتف تعرض القوائم لوحات قصيرة فوق الخريطة؛ عند الفيديو تختفي بطاقة المعلومات بصريًا وتعود عند الإغلاق. اختيار الموقع يفتح بطاقته ويقربه ويحدد الرمز؛ «عرض الجميع» وزر «عرض مصر كاملة» يزيلان التحديد والتصفية ويسترجعان حدود مصر، خلافًا للسلوك السابق الذي كان يمسح المورد فقط دون إصلاح الزوم. الرموز التسعة تبقى مرتبطة بإحداثياتها، ومصدر الصور ظاهر.

نافذة الفيديو متوسطة داخل منطقة الخريطة، بتشغيل يدوي وإغلاق وملء شاشة إن دعمه المتصفح وحالة غياب وفشل وإعادة المحاولة. يستعيد الإغلاق التركيز ويحافظ على الموقع وبطاقة المورد. لا فيديو فعلي مرفق بالعينة؛ اختبرت حالة الغياب والفشل ببيانات واجهة اختبارية، ولم أدّع تشغيل ملف كامل أو اختبار ملء الشاشة الفعلي.

توحيد RobotGuide في البداية والاختيار ومساعد الذكاء الاصطناعي والخرائط والعناصر القديمة التي تعرض روبوتًا. معرفات تدرجات SVG فريدة لكل نسخة لمنع تداخلها. اقتصر كتالوج التجربة على الرابع والخامس والسادس (فصلان وثلاث وحدات)، مع إبقاء الدروس غير المكتملة معطلة وواضحة.

رفع الصورة من بطاقة المورد هو معاينة محلية مؤقتة (PNG/JPG/WebP/GIF، حتى 8 ميجابايت)، ولا يتجاوز صلاحيات النشر أو الرفع. لحفظ صورة مشتركة: الإدارة > تحرير الدرس > الموارد > رابط/رفع صورة > حفظ. تحقق اختبار خادم معزول من رفع PNG بالإدارة، ومنع الطالب من رفعها، ومنع الاطلاع عليها قبل إتاحتها داخل درس مخوّل، ثم إرجاع نفس بايتاتها بعد ربطها ونشر الدرس. لا تعديل لقاعدة المستخدم الفعلية.

النقاط: نجح التصحيح الحقيقي للزائر دون نقاط رسمية. اختبار حساب الطالب في قاعدة مؤقتة أكد منح مكافأة إكمال 30 مرة واحدة، وإرجاع 0 عند التكرار وبقاء الإجمالي 30 بعد إعادة فتح القاعدة. لم يغير هذا التحديث قيم المكافآت.

فحص Chromium: 1440×900، 1366×768، 390×844، 360×740. فتح/طي اللوحات، اتساع الخريطة، اختيار المواقع، إرفاق صورة ومعاينة blob، فتح الفيديو وإغلاقه وEscape، المساران لإعادة جميع العلامات والتحديد والزوم، ثلاثة خيارات درس مع تعطيل غير الجاهز، وعدم تمرير المستند أو أخطاء JS. تحققت أيضًا قائمة الصفوف الثلاثة والروبوت في الاختيار. حسابات الاختبار الدائمة لم تُنشأ. npm run check وnpm test (5/5) وnpm run build ناجحة.

لقطات STUDIO_RESOURCE وSTUDIO_VIDEO وSTUDIO_MAP في screens. هذا المستند يصف التصميم الحالي ويستبدل مرحلة popup التي كانت تجمع الفيديو والملخص.
