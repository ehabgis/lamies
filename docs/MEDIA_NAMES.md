# أسماء الصور والفيديوهات لكل نشاط (2026-10-23)

كل الملفات داخل المجلد `public/lesson-media/`. يقبل البرنامج هذه الصيغ:

- **الصور:** `jpg` أو `jpeg` أو `png` أو `webp`.
- **الفيديو:** `mp4` أو `webm` بترميز H.264.
- **غير مقبول:** `jfif` و`heic` و`mov`. حوّلها أولًا؛ HitPaw أو HandBrake يكفي.

بعد وضع الملفات:

1. شغّل `npm run media`. يقول لك أي ملف اسمه خطأ أو صيغته غير مقبولة.
2. أعد تحميل الصفحة. لا حاجة لإعادة تشغيل البرنامج.

| المجلد | يظهر في | الأسماء |
|---|---|---|
| `sites/` | بطاقة الموقع على خريطة الدرس + صور رحلة كنوز مصر + صور بطاقات مشروعات الدرس الثالث | اسم الموقع (الجدول بالأسفل) |
| `water/` | رحلة المياه (الدرس الثاني)، شاشة «شاهد واكتشف» | `farm` · `oasis` · `coast` |
| `projects/` | رحلة «نكتشف مشروعات مصر» (الدرس الثالث) | `wheat` · `fish` · `solar` لـ«شاهد واكتشف»، و`new-delta` · `birket-ghalioun` · `benban-solar` لصورة المشروع |

لا تحتاج هذه الأنشطة صورًا: «ابنِ خريطتك» (رموز على الخريطة)، والأنشطة التفاعلية (صنّف، صِل، رتّب…)، وإنجازاتي والشهادة.

## 1) `sites/` — صور المواقع (مجلد واحد لكل الدروس)

- **الصورة الأولى:** `اسم-الموقع.jpg`، مثل `iron-bahariya.jpg`.
- **صور إضافية:** `iron-bahariya-2.jpg` حتى `iron-bahariya-6.jpg`.
- **الفيديو:** `iron-bahariya.mp4`.
- **رحلة كنوز مصر:** تأخذ صورة المورد من أول موقع له، فالحديد من `iron-bahariya.jpg`، والبترول من `oil-gulf-suez.jpg`، وهكذا.
- **غلاف بطاقتي المهمتين في رحلة كنوز مصر:** `trip-minerals.jpg` لـ«كنوز المعادن»، و`trip-energy.jpg` لـ«مصادر الطاقة». بدونهما تظهر رموز الموارد.
- **بطاقات مشروعات الدرس الثالث:** تأخذ صورة المشروع من `projects/` أولًا، فإن لم توجد تأخذها من هنا، مثل `birket-ghalioun.jpg`.
