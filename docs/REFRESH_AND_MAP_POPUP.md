# تحديث البداية والاختيارات ونافذة الموقع

طلبات المستخدم: تصحيح «الزكية» إلى «الذكية»، إزالة سطر لميس والعبارات والشريط الأبيض حول «مصر مليانة حكايات» وعلامة «هنا مصر»، إبراز «ابدأ المغامرة»، واستخدام RobotGuide الموجود داخل التطبيق أسفل رسم المستكشف. بقي الدخول للحساب مستقلًا بعنوان واضح «سجّل الدخول وابدأ».

المادة ثابتة بالدراسات الاجتماعية؛ أزيل اختيارها وبقي الربط مع subject في بنية الخادم. الكتالوج التجريبي يقدم الأول حتى السادس وفصلين وثلاث وحدات. الوحدتان الأولى والثانية تضمان خانة درس قيد التجهيز. الثالثة تضم عناوين المستخدم الثلاثة. الثروة المعدنية متاحة للصف الخامس (نفس العينة في الفصلين، دون ادعاء اعتماد التوزيع)، والمياه والمشروعات وبقية الصفوف قيد التجهيز. لا اختلاق لمحتوى أو نشر CMS. إذا خلا كتالوج الطالب من الدروس، تعرض الواجهة العينة بدل طريق مسدود، وتفتح demo عند بدء درس العينة دون تسجيل درجات رسمية. عند وجود دروس منشورة تظل مسارات الحساب والتسجيل محفوظة.

تعرض Leaflet popup على إحداثيات الموقع محتوى React عبر portal، بتبويبين للفيديو والملخص والخصائص. أزيلت بطاقة الموقع من الجانب أثناء تحديده، واتسعت الخريطة على الكمبيوتر. النافذة غير حاجزة، قابلة للإغلاق وإعادة الفتح، ويُعاد مركز الموقع عند الإغلاق كي لا تُحجب العلامة بشريط الإسناد. حجم المحتوى محدود مع تمرير داخلي؛ على الهاتف تختفي أدوات الخريطة المتراكبة مؤقتًا حتى إغلاق النافذة. تظل نسب الصور إلى Esri ظاهرة. يتحدث ارتفاع النافذة عند تغيير حجم الخريطة.

الفيديو يستخدم رابط المورد إن توفر، مع حالة غياب واضحة، ولا تشغيل تلقائي أو ملفات مختلقة. تبقى الأسئلة والمساعدة وملخص الدرس متاحة. اختبارات المتصفح الفعلية (Chromium، 1440×900 و390×844 و360×740): نصوص البداية والروبوت وزر المغامرة؛ الصفوف الستة والفصل الثاني والوحدات الثلاث؛ تعطيل الدروس غير الجاهزة؛ فتح عينة الصف الخامس؛ نافذة الموقع فوق Esri وتبويبات لوحة المفاتيح وإغلاقها وإعادة فتحها؛ عدم وجود تمرير خارجي أو أخطاء JavaScript. لا اختبار هاتف حقيقي أو ملف فيديو كامل في هذه الجولة.

اختبار الخادم يتحقق من ستة صفوف و12 فصلًا و36 وحدة ومعرفات فريدة، مع درسين متاحين يعيدان نفس العينة الآمنة فقط. تبقى بقية اختبارات المصادقة والصلاحيات والتصحيح والمكافآت ناجحة. npm run check وnpm test (5/5) وnpm run build.

صور REFRESH_ENTRY_*.png وREFRESH_UNITS_*.png وREFRESH_POPUP_*.png تحت docs/screens تسجل النتيجة. الوثائق السابقة تصف المراحل الأقدم؛ هذا التحديث يستبدل مكان بطاقة الموقع والهيكل التجريبي السابق.
