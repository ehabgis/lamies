# نشر نسخة الاختبار على Render

Web Service من جذر المستودع، الفرع `feature/lamis-platform`.

- Node.js: `24` عبر `NODE_VERSION`.
- Build Command: `npm ci && npm run build`.
- Start Command: `npm start`.
- `HOST=0.0.0.0`، واترك Render يحدد `PORT`.
- `COOKIE_SECURE=true`.
- `APP_ORIGIN`: رابط HTTPS الفعلي للخدمة، دون شرطة أخيرة. يجب ضبطه قبل اختبار الكتابة لأن TLS ينتهي عند وكيل Render.
- Health Check Path: `/api/health`.

الخادم يعرض `dist` فقط، ويدعم فتح روابط React مباشرة وتحديثها. مسارات `/api` غير الموجودة تبقى JSON 404؛ الملفات المفقودة لا تستبدل بصفحة HTML. لا ينشر مجلد المشروع أو البيانات الخاصة.

## البيانات

للحفاظ على الحسابات والملفات، أضف Persistent Disk إلى خدمة تدعم ذلك (خيار مدفوع) في `/var/data` واضبط:

```text
LAMIS_DB=/var/data/lamis.sqlite
UPLOAD_DIR=/var/data/uploads
```

بدون قرص دائم هذه نسخة اختبار مؤقتة؛ قاعدة البيانات والرفع قد يضيعان بعد إعادة التشغيل أو النشر. لا تفترض أن اختيار خطة حوسبة مدفوعة وحده يضيف القرص.

أنشئ أول مشرف بواسطة `npm run bootstrap` من Shell الخدمة مع إدخال بياناته الخاصة وفق `server/README.md`. لا توجد كلمة مرور افتراضية. لا تضع أسرارًا في Git. تجربة الزائر متاحة دون إنشاء مشرف؛ المحتوى التجريبي لا يمثل نشر دروس معتمدة.

## التحقق بعد النشر

افتح `/` ثم `/explore` و`/demo/lesson-1`، وحدّث صفحة الدرس مباشرة. تحقق من صور الخريطة والوسائط والأسئلة والصوت باللمس على الهاتف. اختبر التسجيل/الدخول والكتابة بعد ضبط `APP_ORIGIN`. مع القرص الدائم تحقق من استمرار البيانات بعد إعادة التشغيل. لا يحتاج اختبار الزائر مفتاح OpenAI.

التحقق المحلي يغطي اختبارات HTTP والبناء. النشر الفعلي وSafari على هاتف حقيقي يحتاجان التحقق بعد الحصول على رابط الخدمة.

## المعلم الذكي عبر Cloudflare

1. في Cloudflare افتح Workers AI ثم Use REST API. أنشئ رمزًا من قالب Workers AI، وانسخ Account ID. لا تضع الرمز في الشات أو في المستودع أو في متغير يبدأ بـ `VITE_`.
2. بعد أخذ نسخة احتياطية من SQLite والوسائط وضمان وجود تخزين دائم، أضف في Render → Environment المتغيرات التالية:

   | المتغير | القيمة |
   | --- | --- |
   | `AI_PROVIDER` | `cloudflare` |
   | `CLOUDFLARE_ACCOUNT_ID` | معرّف الحساب |
   | `CLOUDFLARE_AI_TOKEN` (أو `CLOUDFLARE_API_TOKEN`) | رمز Workers AI؛ يكفي أحد الاسمين |
   | `CLOUDFLARE_AI_MODEL` | اختياري؛ الافتراضي `@cf/meta/llama-3.3-70b-instruct-fp8-fast` |
   | `AI_STUDENT_ENABLED` | `false` لبدء اختبار فريق التعليم؛ `true` ليصل المعلم الذكي للطلاب والزوار |

3. انشر نسخة الكود التي تدعم Cloudflare. حالة مزوّد المعلم في `/api/ai/status`؛ الجاهزية تعني أن إعدادات الاتصال موجودة، ويؤكّد السؤال التجريبي صحة الرمز والاتصال. لا يستدعي فحص الحالة المزود.
4. اختبر من حساب مشرف أو معلم داخل درس منشور عبر `/classroom/lesson-1`؛ لن يعمل في `/demo/lesson-1` أو في المعاينة. جرّب سؤالًا عربيًا يطابق مصدرًا مراجعًا وسؤالًا خارج الدرس. عند انتهاء الحصة يبقى الشرح المكتوب والتلميحات متاحين. بعد اختبار الجودة ومراجعة شروط المزود وملاءمة إرسال أسئلة الطلاب، يمكن للمسؤول إتاحة الخدمة للطلاب بـ `AI_STUDENT_ENABLED=true`.

نفس الإعدادات تشغّل كل ميزات المعلم الذكي: `/api/ai`، وبطاقات المساعدة في «أسئلة الدرس» و«أكمل الفراغ» (`.../help`)، ومحادثة الدرس على الخريطة (`.../ask`)، بما فيها الدروس التجريبية `/demo/lesson-x`. إذا ضُبطت `CLOUDFLARE_ACCOUNT_ID` والرمز دون `AI_PROVIDER` يُختار Cloudflare تلقائيًا. مع `AI_STUDENT_ENABLED=false` يرى الطلاب والزوار الشرح المعدّ من الدرس، ويستخدم حساب المعلم أو الإدارة النموذج.

مرجع المزود: [Workers AI REST API](https://developers.cloudflare.com/workers-ai/get-started/rest-api/) و[الحصة المجانية](https://developers.cloudflare.com/workers-ai/platform/pricing/).

## نشر أول درس فعلي

ابدأ بمسودة «الخامات المعدنية ومصادر الطاقة في مصر» (`lesson-1`). في `/admin` افتح **المحتوى** بحساب مدير المنصة أو مدير المحتوى:

1. تحقق من الصف والفصل والعام والوحدة مقابل نسخة كتاب الطالب المستخدمة فعليًا.
2. في **إضافة مصدر معرفي** أضف عنوان المرجع والطبعة والصفحة أو الرابط، وفقرة قصيرة بصياغة مدرسية تستند إليه. علّم **مصدر مُراجع ومعتمد** بعد التحقق. اجعل لكل موضوع فقرة مستقلة لكي يصل المعلم إلى المصدر المناسب.
3. راجع الأهداف والشرح والأسئلة وإجاباتها وتلميحاتها، ومواقع الخريطة والوسائط المتاحة. راجع الدرس عبر المعاينة، ثم علّم **تمت مراجعة الحقائق والمواقع والوسائط تربويًا** عند اكتمالها.
4. انشر الوحدة وجميع الأسلاف غير المنشورين. في الدرس اختر **منشور للطلاب** ثم احفظ. اختبر بحساب طالب مسجل في الصف والفصل والعام الصحيحين من **رحلتي** (`/journey`)؛ الدرس الفعلي يفتح عبر `/classroom/lesson-1` وتحفظ محاولاته في قاعدة بيانات المنصة.

مراجعة المدرس اعتماد داخل لميس، وليست شهادة اعتماد من الوزارة. لا يغيّر تركيب المزود حالة أي درس أو سجل طالب.
