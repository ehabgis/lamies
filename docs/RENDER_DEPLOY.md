# نشر نسخة الاختبار على Render

Web Service من جذر المستودع، الفرع `feature/lamis-platform`.

- Node.js: `24` عبر `NODE_VERSION`.
- Build Command: `npm ci && npm run build`.
- Start Command: `npm start`.
- `HOST=0.0.0.0`، واترك Render يحدد `PORT`.
- `COOKIE_SECURE=true`.
- `APP_ORIGIN`: رابط HTTPS الفعلي للخدمة، دون شرطة أخيرة. يجب ضبطه قبل اختبار الكتابة لأن TLS ينتهي عند وكيل Render.
- Health Check Path: `/api/health`.

الخادم يعرض `dist` فقط، ويدعم فتح روابط React مباشرة وتحديثها. مسارات `/api` غير الموجودة تبقى JSON 404؛ الملفات المفقودة لا تستبدل بصفحة HTML. لا ينشر مجلد المشروع أو البيانات الخاصة.

## البيانات

للحفاظ على الحسابات والملفات، أضف Persistent Disk إلى خدمة تدعم ذلك (خيار مدفوع) في `/var/data` واضبط:

```text
LAMIS_DB=/var/data/lamis.sqlite
UPLOAD_DIR=/var/data/uploads
```

بدون قرص دائم هذه نسخة اختبار مؤقتة؛ قاعدة البيانات والرفع قد يضيعان بعد إعادة التشغيل أو النشر. لا تفترض أن اختيار خطة حوسبة مدفوعة وحده يضيف القرص.

أنشئ أول مشرف بواسطة `npm run bootstrap` من Shell الخدمة مع إدخال بياناته الخاصة وفق `server/README.md`. لا توجد كلمة مرور افتراضية. لا تضع أسرارًا في Git. تجربة الزائر متاحة دون إنشاء مشرف؛ المحتوى التجريبي لا يمثل نشر دروس معتمدة.

## التحقق بعد النشر

افتح `/` ثم `/explore` و`/demo/lesson-1`، وحدّث صفحة الدرس مباشرة. تحقق من صور الخريطة والوسائط والأسئلة والصوت باللمس على الهاتف. اختبر التسجيل/الدخول والكتابة بعد ضبط `APP_ORIGIN`. مع القرص الدائم تحقق من استمرار البيانات بعد إعادة التشغيل. لا يحتاج اختبار الزائر مفتاح OpenAI.

التحقق المحلي يغطي اختبارات HTTP والبناء. النشر الفعلي وSafari على هاتف حقيقي يحتاجان التحقق بعد الحصول على رابط الخدمة.
