# شاشة الاختيار الدراسي

المساران: `/explore` لتصفح العينة دون حساب، و`/journey` بعد دخول الطالب. زر صفحة البداية يفتح الاختيار بدل الانتقال المباشر للخريطة. تبقى الروابط القديمة `/demo/lesson-1` صالحة.

ثلاث خطوات: العام/المرحلة/الصف، ثم الفصل/المادة، ثم الوحدة ودروسها. العام ظاهر أولًا؛ تربط الواجهة اسم العام بفرع الفصل في نموذج البيانات القائم دون تغيير مخطط التسجيل. تغيير أي اختيار يمسح التابع له. لا يمكن الانتقال قبل اكتمال الخطوة. عند بدء درس بحساب تحفظ الواجهة التسجيل عبر API وتنتظر نجاحه قبل فتح الدرس. الخطأ يبقي الاختيارات للمحاولة مجددًا. يمكن تعديل الخطوات السابقة؛ ينتقل تركيز لوحة المفاتيح إلى عنوان الخطوة.

`GET /api/demo/catalog` يعيد سبعة عناصر وصفية للعينة الثابتة فقط، من العام 2026 / 2027 والصف الخامس/الفصل الأول إلى الدراسات الاجتماعية/كنوز مصر/درس الخامات المعدنية والطاقة. ليست اعتمادًا للمنهج. لا يقرأ مسودات CMS أو يعرض محتوى الأسئلة. الكتالوج المنشور والتسجيل والتقدم تبقى محمية. لا نشر تلقائي ولا حفظ درجات للتجربة.

تحقق Chromium: الرحلة الحقيقية للزائر حتى فتح الدرس، تعطيل الأزرار والقوائم التابعة، إعادة الاختيار، خطأ التحميل وإعادة المحاولة. اختبار واجهة الحساب باستجابات API اختبارية تحقق من حمولة التسجيل والانتقال إلى classroom؛ المصادقة الحقيقية والحفظ والصلاحيات يغطيها اختبار الخادم القائم، ولم تُنشأ حسابات دائمة في هذه الجولة.

مقاسات 1440×900 و1366×768 و390×844 و360×740: لا تمرير خارجي أو داخلي لازم في خطوات العينة. المقاس الأفقي 844×390: تمرير داخلي مقصود دون قص عناصر. ليست هذه ضمانًا لكل أحجام الخطوط أو لوحة مفاتيح هاتف فعلي. لا أخطاء JavaScript في رحلة الاختيار. لقطات `screens/SELECTION_*.png` تسجل الحالة الافتراضية والدروس المختارة على الكمبيوتر والهاتف.

الفحوص المطلوبة: `npm run check` و`npm test` (5 ناجحة، يتضمن اختبار التجربة الآن سلسلة الكتالوج وعدم وجود محتوى إجابات) و`npm run build`.
