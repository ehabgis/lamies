# رفع الصور والفيديوهات إلى GitHub ثم Render

## لماذا لم ترفع كل الملفات؟
- **الرفع من صفحة GitHub** (Add files via upload): لا يقبل ملفًا أكبر من 25 ميجابايت، ولا أكثر من 100 ملف في المرة.
- **git أو GitHub Desktop:** لا يقبل ملفًا أكبر من 100 ميجابايت.
- **الفيديوهات** غالبًا أكبر من هذا لأنها بجودة الكاميرا. والفيديو الكبير ثقيل على الطالب أيضًا.

## الحل (بالترتيب)

### 1) صغّر الفيديو قبل الرفع (الأهم)
**بـ HandBrake (مجاني):**
1. افتح الفيديو.
2. اختر Preset ← **Web ← Creator 720p60**، أو **General ← Fast 720p30**.
3. الصيغة MP4، والترميز **H.264**، وليس H.265.
4. لو المقطع أطول من دقيقة، قصّه إلى 20–40 ثانية من تبويب Range.
5. احفظه بالاسم الصحيح، مثل `farm.mp4`.

**بـ HitPaw:** اختر MP4، والترميز H.264، والدقة 720p.

**الهدف:** أقل من 20 ميجابايت لكل فيديو. 30 ثانية بدقة 720p تكون نحو 5–10 ميجابايت.

**الصور:** يكفي عرض 1600 بكسل، وحجم أقل من 1 ميجابايت.

### 2) ارفع على دفعات
- **من الموقع:** ارفع في كل مرة أقل من 100 ملف، وكل ملف أقل من 25 ميجابايت. اختر مجلد `public/lesson-media/sites/` (أو `water/` أو `projects/`) ثم Add file ← Upload files.
- **أو من GitHub Desktop:** انسخ الملفات إلى نفس المجلد على جهازك، ثم Commit ثم Push. يقبل حتى 100 ميجابايت للملف.
- **الفرع:** الصحيح `feature/lamis-platform`، أو أي فرع يبني منه Render.

### 3) تأكد قبل الرفع وبعده
- شغّل `npm run media`. يظهر حجم كل ملف ونوع ترميز الفيديو، وأي اسم خطأ.
- بعد الرفع، Render يعيد البناء تلقائيًا إذا كان Auto-Deploy مفعّلًا. وإلا اضغط Manual Deploy.

## ما لا يُنصح به
- **رفع الملفات على Render نفسه:** القرص يُمسح مع كل نشر جديد.
- **Git LFS:** يحتاج إعدادًا إضافيًا في Render، ومساحته المجانية على GitHub صغيرة.
